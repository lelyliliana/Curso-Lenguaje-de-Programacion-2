Laboratorio 04

Entrada y salida de datos

Capturar información del usuario y mostrar resultados utilizando diferentes métodos de JavaScript.

Área de experimentación

Presiona el botón para iniciar la interacción con JavaScript.

Resultado

Aquí aparecerá la información ingresada por el usuario.

Observaciones

El método prompt() permite capturar datos, alert() muestra mensajes y confirm() solicita una respuesta de aceptación o cancelación.

Reto

Solicita también la ciudad del usuario y muéstrala junto con los demás datos.
