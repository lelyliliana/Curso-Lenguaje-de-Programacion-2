# JavaScript

## Laboratorios interactivos

Esta sección contiene los laboratorios desarrollados para aprender JavaScript de manera progresiva mediante ejercicios prácticos y aplicaciones funcionales.

Cada laboratorio introduce uno o varios conceptos nuevos y reutiliza los conocimientos adquiridos en los laboratorios anteriores.

---

# Objetivos

Al finalizar esta sección el estudiante será capaz de:

- Declarar variables.
- Trabajar con tipos de datos.
- Utilizar operadores.
- Capturar información del usuario.
- Implementar estructuras condicionales.
- Utilizar ciclos.
- Crear funciones reutilizables.
- Trabajar con arrays y objetos.
- Manipular el DOM.
- Responder a eventos.
- Validar formularios.
- Almacenar información mediante Local Storage.
- Consumir servicios web utilizando Fetch.
- Desarrollar aplicaciones web sencillas utilizando JavaScript.

Para obtener un mejor aprovechamiento del material se recomienda:

3. Modificar los ejemplos para experimentar.
4. Resolver el reto planteado al finalizar cada práctica.
5. Repetir los laboratorios antes de avanzar al siguiente.
