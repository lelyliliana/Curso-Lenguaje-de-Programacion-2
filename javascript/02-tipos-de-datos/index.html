Laboratorio 02

Tipos de datos en JavaScript

Identificar los principales tipos de datos de JavaScript mediante el operador typeof.

Área de experimentación

Presiona el botón para identificar el valor y el tipo de dato de cada variable.

Resultado

Aquí aparecerán los tipos de datos identificados con JavaScript.

Observaciones

El operador typeof permite conocer el tipo de dato almacenado en una variable.

Reto

Agrega una variable de tipo arreglo y otra de tipo objeto. Luego muestra sus valores y sus tipos de datos.
