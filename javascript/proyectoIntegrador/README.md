**Nivel:** Integrador

**Duración estimada:** 2 a 4 horas

**Requisitos previos:**

- Operadores
- Entrada y salida de datos
- Condicionales
- Ciclos
- Funciones
- Arrays
- Objetos
- DOM
- Eventos

**Concepto principal:**

Integrar los conocimientos adquiridos durante el curso en una aplicación web funcional.

---

# Objetivo

Desarrollar un Sistema de Gestión de Estudiantes aplicando de manera integrada los principales conceptos estudiados durante el curso de JavaScript.

---

# Descripción

Este proyecto representa la integración de todos los laboratorios desarrollados durante el curso.

El sistema permite registrar estudiantes, almacenarlos localmente, consultarlos, buscarlos y eliminarlos mediante una interfaz desarrollada completamente con HTML, CSS y JavaScript.

El proyecto constituye un ejemplo de una aplicación web funcional que puede servir como base para desarrollos de mayor complejidad.

---

# Funcionalidades

El sistema permite:

- Registrar estudiantes.
- Validar información.
- Crear objetos JavaScript.
- Almacenar múltiples estudiantes.
- Buscar estudiantes.
- Eliminar estudiantes.
- Mostrar estadísticas básicas.
- Guardar la información mediante Local Storage.
- Recuperar automáticamente la información al abrir nuevamente la aplicación.

# Cómo ejecutar el proyecto

1. Abra la carpeta `javascript/proyectoIntegrador`.
2. Ejecute el archivo `index.html`.
3. Registre uno o varios estudiantes.
4. Utilice el buscador.
5. Elimine registros.
6. Recargue la página.
7. Verifique que la información permanece almacenada.

# Conclusiones

El Proyecto Integrador representa el cierre del proceso de aprendizaje desarrollado durante el curso **Lenguaje de Programación II**.

Más allá de implementar una aplicación funcional, el propósito principal consiste en demostrar cómo los diferentes conceptos estudiados —desde las variables hasta el almacenamiento local— trabajan de manera conjunta para resolver un problema real.

Este proyecto constituye una base sólida para continuar el aprendizaje de tecnologías como React, Vue, Angular o cualquier otro framework de desarrollo Front-End.
