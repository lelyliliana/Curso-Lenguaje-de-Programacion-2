# Laboratorio 10: Revisión y publicación del Proyecto Web

**Nivel:** Intermedio

**Duración estimada:** 60 minutos

**Requisitos previos:**

- Haber completado los laboratorios 01 al 09.
- Contar con el Proyecto Web Personal completamente desarrollado.

**Concepto principal:**

Revisar, validar y publicar el Proyecto Web Personal.

---

# Objetivo

Realizar la revisión final del Proyecto Web Personal y preparar su publicación utilizando GitHub y Netlify.

---

# Descripción

Durante los laboratorios anteriores se construyó progresivamente el diseño visual del Proyecto Web Personal.

En esta práctica no se incorporarán nuevas propiedades CSS.

El propósito consiste en revisar el proyecto completo, verificar el funcionamiento de todos los componentes y preparar la primera versión publicada del sitio.

Se comprobará que:

- La estructura HTML sea correcta.
- La hoja de estilos se encuentre organizada.
- Las imágenes se visualicen correctamente.
- La galería responda adecuadamente.
- El formulario mantenga una apariencia consistente.
- El sitio sea adaptable.
- No existan rutas incorrectas.

---

# Evolución del proyecto

Al finalizar este laboratorio el Proyecto Web Personal contará con:

- ✅ Estructura HTML completa.
- ✅ Identidad visual.
- ✅ Componentes reutilizables.
- ✅ Menú moderno.
- ✅ Distribución mediante Flexbox.
- ✅ Galería mediante Grid.
- ✅ Formularios modernos.
- ✅ Diseño adaptable.
- ✅ Primera versión lista para publicación.

# Competencia

Al finalizar este laboratorio el estudiante será capaz de revisar, validar y publicar un sitio web desarrollado con HTML y CSS.

- [ ] La navegación es correcta.
- [ ] El formulario conserva su estructura.

---

## CSS

- [ ] El menú responde correctamente.
- [ ] Flexbox funciona.

- [ ] El formulario mantiene una apariencia uniforme.
- [ ] El diseño adaptable responde correctamente.

---

- [ ] Todas las imágenes cargan.

# Validación

Antes de publicar el proyecto:

- Revise la indentación.
- Elimine código innecesario.
- Compruebe todas las rutas.
- Verifique el funcionamiento del menú.
- Revise el formulario.
- Compruebe la adaptación a diferentes tamaños de pantalla.

# Publicación en GitHub

Actualice el repositorio.

```bash
git add .
```

```bash
git commit -m "Completar módulo CSS"
```

```bash
git push
```

---

# Publicación en Netlify

Una vez actualizado GitHub:

1. Ingrese a Netlify.
2. Seleccione **Add new site**.
3. Importe el repositorio.
4. Espere la publicación.
5. Verifique el enlace generado.

# Buenas prácticas

- Mantener una estructura organizada.
- Evitar código duplicado.
- Mantener comentarios únicamente cuando aporten claridad.
- Utilizar nombres descriptivos.
- Verificar todas las rutas.
- Revisar el sitio en diferentes navegadores.
- Comprobar la adaptación a diferentes dispositivos.
- Publicar únicamente versiones estables.

# Reto

Antes de publicar:

1. Personalice completamente el sitio.
2. Sustituya los textos de ejemplo.
3. Cambie las imágenes por las de su proyecto.
4. Revise la ortografía.
5. Compruebe todos los enlaces.
6. Verifique el funcionamiento del formulario.
7. Publique el sitio y comparta el enlace.

# Conclusiones

El desarrollo de un sitio web no termina cuando el diseño está terminado.

Antes de publicar es necesario revisar cuidadosamente todos los recursos, comprobar el funcionamiento de cada componente y validar el comportamiento del sitio en diferentes dispositivos.

Este laboratorio marca el cierre del módulo de CSS y deja preparado el Proyecto Web Personal para incorporar comportamiento mediante JavaScript.
