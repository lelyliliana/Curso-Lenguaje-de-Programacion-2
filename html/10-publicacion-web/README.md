# Laboratorio 10: Revisión y publicación del Proyecto Web

**Nivel:** Básico

**Duración estimada:** 60 minutos

**Requisitos previos:**

- Haber completado los laboratorios 01 al 09.

**Concepto principal:**

Revisar, validar y publicar el Proyecto Web Personal.

---

# Objetivo

Realizar la revisión final del Proyecto Web Personal y preparar su publicación utilizando GitHub y Netlify.

---

# Descripción

Durante los laboratorios anteriores se construyó progresivamente el Proyecto Web Personal.

En esta práctica no se desarrollarán nuevas secciones.

El propósito consiste en revisar la estructura del proyecto, verificar el funcionamiento de cada elemento y preparar la primera versión publicada del sitio web.

El estudiante comprobará que:

- El documento HTML sea correcto.
- Las imágenes se carguen.
- Los archivos multimedia funcionen.
- El formulario esté correctamente estructurado.
- Las rutas sean válidas.
- El sitio pueda publicarse sin errores.

# Lista de verificación

Antes de publicar el proyecto revise los siguientes aspectos.

## Documento

- [ ] El documento inicia con `<!DOCTYPE html>`.
- [ ] El idioma está correctamente definido.
- [ ] Existe un único `<h1>`.
- [ ] El documento contiene `<header>`, `<main>` y `<footer>`.

## Navegación

- [ ] Todos los enlaces funcionan.
- [ ] El enlace "Volver al inicio" funciona correctamente.

## Imágenes

- [ ] Todas las imágenes cargan.
- [ ] Cada imagen tiene atributo `alt`.

## Multimedia

- [ ] El video se reproduce.
- [ ] El audio se reproduce.

## Formularios

- [ ] Todos los controles tienen `<label>`.
- [ ] Los identificadores (`id`) son únicos.

## Organización

- [ ] La carpeta `img` contiene únicamente imágenes.
- [ ] La carpeta `multimedia` contiene únicamente audio y video.

# Validación

Antes de publicar el sitio:

- Revise el código HTML.
- Compruebe que no existan errores de sintaxis.
- Verifique todas las rutas.
- Compruebe que no existan archivos innecesarios.

---

# Publicación en GitHub

Actualice el repositorio.

```bash
git add .
```

```bash
git commit -m "Completar módulo HTML"
```

```bash
git push
```

---

# Publicación en Netlify

Una vez actualizado el repositorio:

1. Ingrese a Netlify.
2. Seleccione **Add new site**.
3. Importe el repositorio desde GitHub.
4. Espere la publicación.
5. Verifique el enlace generado.

# Buenas prácticas

- Mantener una estructura organizada.
- Utilizar nombres descriptivos.
- No dejar archivos sin utilizar.
- Verificar todas las rutas antes de publicar.
- Comprobar el sitio después de cada actualización.

# Reto

Antes de publicar:

- Personalice completamente el sitio.
- Reemplace todos los textos de ejemplo.
- Cambie las imágenes por las correspondientes a su proyecto.
- Actualice la información personal.
- Verifique que todos los enlaces funcionen.
- Publique el sitio y comparta el enlace.
