Laboratorio 01

Estructura básica de un documento HTML

En este laboratorio aprenderemos a construir la estructura mínima de una página web.

Objetivo

Identificar los elementos fundamentales que componen un documento HTML.

Elementos de la estructura HTML

La declaración <!DOCTYPE html> indica que el documento utiliza HTML5.

La etiqueta <html> contiene todo el documento.

La sección <head> almacena información que no se muestra directamente en la página.

La etiqueta <body> contiene todo el contenido visible.

Observaciones

El código debe mantenerse correctamente indentado para facilitar su lectura.

También se recomienda declarar el idioma mediante el atributo lang="es".

Reto

Cambia el título de la página y agrega un párrafo con una breve presentación personal.
