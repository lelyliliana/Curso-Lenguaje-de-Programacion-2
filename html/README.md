# Módulo de HTML

Bienvenido al módulo de **HTML** del curso **Lenguaje de Programación II**.

Durante este módulo construiremos progresivamente el **Proyecto Web Personal**, el cual servirá como base para los módulos de CSS, JavaScript y React.

El objetivo no es desarrollar ejercicios independientes, sino crear un único proyecto que evolucionará a lo largo de todo el curso.

---

# Objetivo del módulo

Construir la estructura completa de un sitio web utilizando HTML5 y buenas prácticas de desarrollo.

Al finalizar este módulo el estudiante dispondrá de un proyecto web organizado, semántico y preparado para incorporar estilos mediante CSS y comportamiento mediante JavaScript.

---

# Metodología

Cada laboratorio representa una nueva versión del mismo proyecto.

El estudiante deberá conservar el trabajo realizado en el laboratorio anterior y continuar desarrollándolo.

La evolución del proyecto será la siguiente:

```text
01 Estructura HTML
        ↓
02 Sobre mí
        ↓
03 Menú de navegación
        ↓
04 Galería
        ↓
05 Formación académica
        ↓
06 Habilidades e intereses
        ↓
07 Contacto
        ↓
08 Presentación multimedia
        ↓
09 HTML avanzado
        ↓
10 Publicación del Proyecto Web
```

No se crearán proyectos diferentes en cada laboratorio.

Todo el trabajo se desarrollará sobre un único sitio web.

# Buenas prácticas

Durante este módulo se aplicarán principios como:

- HTML semántico.
- Accesibilidad.
- Correcta indentación.
- Organización de carpetas.
