# Laboratorio 04: Incorporación de imágenes al Proyecto Web

**Nivel:** Básico

**Duración estimada:** 30 minutos

**Requisitos previos:**

- Laboratorio 01: Creación de la estructura inicial del Proyecto Web.
- Laboratorio 02: Construcción de la sección "Sobre mí".
- Laboratorio 03: Construcción del menú de navegación.

**Concepto principal:**

Incorporar imágenes al Proyecto Web Personal utilizando las etiquetas HTML destinadas al contenido gráfico.

---

# Objetivo

Agregar imágenes al Proyecto Web Personal para enriquecer visualmente el contenido del sitio y comprender el uso correcto de las etiquetas HTML relacionadas con recursos gráficos.

---

# Descripción

Continuaremos desarrollando el **Proyecto Web Personal** incorporando imágenes representativas del sitio.

Durante esta práctica se agregarán una imagen principal, una fotografía de presentación, imágenes para los proyectos desarrollados y una pequeña galería.

Además de aprender a insertar imágenes, se aplicarán buenas prácticas relacionadas con la accesibilidad mediante el atributo `alt` y la organización del contenido utilizando las etiquetas `<figure>` y `<figcaption>`.

---

# Conceptos trabajados

- `<img>`
- `src`
- `alt`
- `width`
- `<figure>`
- `<figcaption>`

---

# Elementos utilizados

| Elemento | Función |
|----------|---------|
| `<img>` | Inserta una imagen en la página. |
| `src` | Indica la ubicación del archivo de imagen. |
| `alt` | Describe la imagen para mejorar la accesibilidad. |
| `width` | Define el ancho de visualización. |
| `<figure>` | Agrupa una imagen con su descripción. |
| `<figcaption>` | Agrega una descripción a la imagen. |

---

# Funcionamiento del laboratorio

Durante esta práctica el estudiante:

1. Agrega la imagen principal del sitio.
2. Incorpora una fotografía de presentación.
3. Presenta imágenes de sus proyectos.
4. Construye una pequeña galería.
5. Organiza las imágenes utilizando `<figure>` y `<figcaption>`.
6. Describe correctamente cada imagen mediante el atributo `alt`.

# Cómo ejecutar el laboratorio

1. Abra la carpeta `html/04-imagenes`.
2. Ejecute el archivo `index.html`.
3. Verifique que todas las imágenes se visualicen correctamente.
4. Revise el código HTML y observe cómo se incorporan los recursos gráficos.

---

# Buenas prácticas

- Utilizar siempre el atributo `alt`.
- Organizar las imágenes mediante `<figure>`.
- Agregar una descripción utilizando `<figcaption>`.
- Utilizar nombres descriptivos para los archivos de imagen.
- Mantener todas las imágenes dentro de una carpeta específica (`img`).
