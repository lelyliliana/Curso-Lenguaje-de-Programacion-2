# Laboratorio 03: Construcción del menú de navegación

**Nivel:** Básico

**Duración estimada:** 25 minutos

**Requisitos previos:**

- Laboratorio 01
- Laboratorio 02

**Concepto principal:**

Construir un menú de navegación utilizando enlaces HTML.

---

# Objetivo

Incorporar un menú de navegación al Proyecto Web Personal mediante enlaces HTML que permitan organizar el contenido del sitio.

---

# Descripción

Todo sitio web necesita un sistema de navegación que facilite el acceso a sus diferentes secciones.

En este laboratorio continuaremos desarrollando el Proyecto Web Personal agregando el menú principal del sitio.

Los enlaces creados inicialmente apuntarán a las diferentes secciones de la misma página y posteriormente evolucionarán hacia un sitio web compuesto por varias páginas.

---

Al finalizar este laboratorio el estudiante será capaz de construir sistemas básicos de navegación utilizando enlaces HTML correctamente estructurados.

---

# Conceptos trabajados

- `<a>`
- `href`
- Enlaces internos
- Enlaces externos
- `target`
- Identificadores (`id`)
- Navegación

---

# Funcionamiento del laboratorio

Durante esta práctica el estudiante:

1. Agrega un menú de navegación al Proyecto Web Personal.
2. Crea enlaces hacia las diferentes secciones del documento.
3. Aprende la diferencia entre enlaces internos y externos.
4. Organiza la navegación utilizando una lista.

# Cómo ejecutar el laboratorio

1. Abra la carpeta `html/03-enlaces`.
2. Ejecute `index.html`.
3. Utilice el menú para desplazarse por la página.
4. Observe el funcionamiento de cada enlace.

---

# Buenas prácticas

- Utilizar textos descriptivos en los enlaces.
- Evitar expresiones como "clic aquí".
- Organizar el menú siguiendo un orden lógico.
- Utilizar rutas relativas cuando sea posible.

---

# Reto

Amplíe el menú agregando las siguientes opciones:

- Inicio
- Sobre mí
- Proyectos
- Formación
- Contacto

Cada opción debe llevar a una sección diferente del documento.

---

# Resultado esperado

El Proyecto Web Personal debe contar con un menú funcional que permita navegar entre las diferentes secciones del sitio.

---

# Conclusiones

Una correcta navegación mejora significativamente la experiencia del usuario y facilita el acceso a la información. Los enlaces constituyen uno de los elementos más importantes del desarrollo web y representan el mecanismo básico de comunicación entre las diferentes páginas de un sitio.
