# Conceptos trabajados

- `<ul>`
- `<ol>`
- `<li>`
- `<dl>`
- `<dt>`
- `<dd>`

---

# Tipos de listas

| Elemento | Función |
|----------|---------|
| `<ul>` | Lista desordenada. |
| `<ol>` | Lista ordenada. |
| `<li>` | Elemento de una lista. |
| `<dl>` | Lista de definiciones. |
| `<dt>` | Término que será definido. |
| `<dd>` | Descripción del término. |

---

# Ejemplo

```html
<h3>Lenguajes de programación</h3>

<ul>

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ul>
```

# Buenas prácticas

- Utilizar listas únicamente cuando exista una relación entre los elementos.
- Elegir el tipo de lista adecuado según la información.
- Evitar utilizar listas únicamente para crear espacios visuales.
- Mantener una correcta jerarquía de títulos antes de cada lista.

# Conclusiones

Las listas permiten organizar información relacionada de manera clara y comprensible.

Las listas desordenadas son útiles cuando el orden no es relevante; las listas ordenadas se utilizan cuando existe una secuencia; y las listas de descripción permiten relacionar términos con sus definiciones.

En este laboratorio se incorporaron estos tres tipos de listas sin eliminar las secciones desarrolladas previamente, manteniendo así la evolución acumulativa del Proyecto Web Personal.
