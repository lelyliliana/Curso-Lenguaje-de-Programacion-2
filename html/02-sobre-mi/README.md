# Competencia

Al finalizar este laboratorio el estudiante será capaz de estructurar información utilizando encabezados, párrafos y elementos de formato de texto para construir una página web organizada y fácil de leer.

# Conceptos trabajados

- `<h1>`
- `<h2>`
- `<h3>`
- `<p>`
- `<strong>`
- `<em>`
- `<mark>`
- `<small>`
- `<hr>`

---

# Elementos utilizados

| Elemento | Función |
|----------|---------|
| `<h1>` | Título principal del sitio. |
| `<h2>` | Título de cada sección. |
| `<h3>` | Subtítulos. |
| `<p>` | Párrafos de contenido. |
| `<strong>` | Resalta información importante. |
| `<em>` | Da énfasis al texto. |
| `<mark>` | Resalta información mediante un fondo de color. |
| `<small>` | Presenta información secundaria. |
| `<hr>` | Separa visualmente las diferentes secciones. |

# Buenas prácticas

- Utilizar un único `<h1>` por página.
- Organizar el contenido con encabezados jerárquicos.
- Escribir párrafos cortos y claros.
- Utilizar `<strong>` únicamente cuando sea necesario resaltar información importante.
- Utilizar `<em>` para enfatizar conceptos.
- Evitar escribir grandes bloques de texto sin estructura.

---
