# Curso Lenguaje de Programación II

## Presentación

Bienvenido al repositorio oficial del curso **Lenguaje de Programación II**.

Este repositorio reúne el material práctico utilizado durante el desarrollo del curso y está organizado mediante módulos progresivos que permiten construir, paso a paso, un mismo proyecto desde sus fundamentos hasta una aplicación web moderna desarrollada con React.

A diferencia de una colección de ejercicios independientes, este curso sigue una metodología basada en un **proyecto acumulativo**, en el que cada laboratorio incorpora nuevos conocimientos sobre el trabajo realizado anteriormente.

---

# Objetivo general

Desarrollar aplicaciones web modernas mediante HTML, CSS, JavaScript y React, comprendiendo progresivamente los fundamentos de la Web, el desarrollo del lado del cliente, la interacción con el usuario y el consumo de servicios web.

---

# Competencia general

Al finalizar el curso, el estudiante será capaz de diseñar, desarrollar e integrar aplicaciones web modernas utilizando tecnologías del lado del cliente, organizando el código mediante buenas prácticas y construyendo interfaces reutilizables listas para producción.

---

# Ruta de aprendizaje

Durante el curso seguiremos la siguiente ruta:

```text
Conceptos Web
        │
        ▼

        │
        ▼
CSS
        │
        ▼
JavaScript
        │
        ▼

        ▼
```

Cada módulo incorpora nuevos conocimientos sobre el mismo proyecto, permitiendo comprender la evolución natural de una aplicación web moderna.

---

# Proyecto del curso

El eje central del curso es el desarrollo del **Proyecto Web Personal**.

Durante los diferentes módulos el proyecto evolucionará progresivamente:

```text
HTML
        ↓
Estructura del sitio

CSS
        ↓
Diseño visual y adaptación

JavaScript
        ↓
Interactividad y comportamiento

React
        ↓
Componentes, estado, efectos, consumo de APIs y publicación
```

Al finalizar el curso, el estudiante contará con una aplicación web completa, organizada y preparada para su publicación.

# Módulos del curso

## Conceptos Web

Introduce los fundamentos del funcionamiento de Internet y de las aplicaciones web.

Contenidos principales:

- Cliente y servidor.
- HTTP.
- JSON y XML.
- Servicios Web.
- REST API.
- Pruebas de APIs.

- Imágenes.

- Tablas.
- Formularios.
- Organización semántica.

## JavaScript

Incorporación de comportamiento e interacción.

Contenidos principales:

# Metodología de trabajo

El curso se desarrolla mediante laboratorios prácticos y progresivos.

Cada laboratorio:

- Parte del trabajo realizado anteriormente.
- Introduce un único concepto principal.
- Incluye ejemplos completamente funcionales.
- Está acompañado por documentación detallada.
- Finaliza con una versión operativa del proyecto.

Esta metodología permite que el estudiante comprenda la evolución natural de una aplicación web moderna.
