# Módulo de Conceptos Web

## Presentación

Antes de comenzar a desarrollar aplicaciones web es necesario comprender cómo funciona realmente la Web.

En este módulo no construiremos programas.

Nuestro objetivo será comprender la arquitectura que hace posible que una aplicación web funcione.

Durante estos laboratorios estudiaremos:

- Internet.
- Web.
- Cliente.
- Servidor.
- Frontend.
- Backend.
- HTTP.
- HTTPS.
- JSON.
- XML.
- Servicios Web.
- REST API.

Estos conceptos permitirán comprender posteriormente el funcionamiento de HTML, CSS, JavaScript, React y el consumo de APIs.

---

# Objetivo del módulo

Comprender la arquitectura básica del desarrollo web moderno y el proceso de comunicación entre clientes, servidores y servicios web.

---

# Metodología

Cada laboratorio desarrolla un concepto específico.

La evolución será la siguiente:

```text
¿Qué ocurre cuando escribimos una dirección web?
                    ↓
Funcionamiento de la Web
                    ↓
Cliente y servidor
                    ↓
HTTP
                    ↓
JSON y XML
                    ↓
Servicios Web
                    ↓
REST API
                    ↓
Exploración de APIs
```

Cada laboratorio responde una pregunta concreta.

Al finalizar el módulo el estudiante comprenderá cómo viaja la información desde un navegador hasta un servidor y cómo posteriormente JavaScript y React consumen esos datos.

# Metodología de aprendizaje

En lugar de memorizar definiciones aisladas, cada laboratorio parte de una pregunta.

Por ejemplo:

> ¿Qué ocurre exactamente cuando escribimos una dirección web y presionamos Enter?

A partir de esa pregunta se construye progresivamente todo el conocimiento del módulo.
